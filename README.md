# HipHop 文化馆 — 期末作业

简要说明：这是一个静态网站示例，包含 5 个页面（index.html 为首页），响应式布局，导航互联，以及 3 张示例 SVG 图片。

快速预览：

1. 在本地打开：用浏览器直接打开 `index.html`。

2. 部署建议：将整个目录推到 GitHub 仓库，然后启用 GitHub Pages（Settings → Pages，选择 `main`/`master` 分支的根目录）。或者使用 Netlify、Vercel 等静态站点托管服务。

结构：

- `index.html` — 首页（轮播、快速入口）
- `mc.html`, `dj.html`, `dance.html`, `graffiti.html` — 内容页
- `css/style.css` — 全局样式
- `js/main.js` — 轮播与导航切换脚本
- `images/` — 包含三张示例 SVG 图片
